# 비공개 상품 관리와 펜 상세 미리보기

이 기능은 승인된 관리자가 상품 소개를 저장하고 검토하는 비공개 도구입니다. 공개 쇼핑몰 게시 기능은 없습니다. 상품을 저장해도 일반 방문자에게 공개되지 않습니다.

## 진입과 권한

- 상품 관리: `/admin?tab=products`
- 저장된 상품 상세 미리보기: `/shop-preview/:id`
- 기본 펜 미리보기: `/shop-preview/unframe-pen`

실제 운영에서는 Google 로그인 후 승인된 관리자 권한이 필요합니다. 이메일 인증을 완료한 계정에 대해 `staffEmails/{email}` 문서의 `active: true` 및 일치하는 `email` 값을 확인합니다. Firebase 프로젝트는 기존 `unframe-main`, 웹 앱은 `1:1003147136936:web:ae4a2bd6ec1ca8ade7179d`를 사용합니다. 상품 문서는 Firestore `products/{id}`에 저장하며 읽기·생성·수정·삭제 모두 승인된 직원에게만 허용합니다.

상품 사진은 기존 비공개 R2 저장소의 `products/{상품 ID}/{UUID}.{jpeg|png|webp}` 경로를 사용합니다. 이미지 Worker는 상품 사진 요청에서도 직원 인증을 검사합니다. 미리보기는 인증된 요청으로 사진을 받아 브라우저 임시 URL로 표시합니다. 페이지의 검색 제외 설정만으로 보호하는 방식이 아닙니다.

## 기본 펜과 구매 연결 상태

운영 데이터의 `products/unframe-pen`에 언프레임 펜 소개와 실제 제품·패키지 사진 두 장을 저장했습니다. 가격은 입력하지 않았으며, 확인되지 않은 심 굵기·잉크 색상·크기·소재·판매 구성은 확인 대기로 남깁니다. 본체 색상 안내를 잉크 색상으로 해석하지 마세요.

펜의 구매 주소는 사용자가 제공한 `https://unframe.imweb.me/shop/?idx=4`로 연결했습니다. 다른 상품은 확정된 상품의 전체 `https://` 주소를 입력하고 저장하면 새 창으로 해당 상품을 엽니다. 구매 주소가 비어 있는 상품은 **구매 주소 연결 대기** 상태로 구매 버튼이 비활성화됩니다. 옵션·수량·재고·주문·결제·배송·교환·반품은 아임웹에서 관리하고 최종 확인합니다.

**아임웹 공식 API와 자동 상품 동기화는 연결하지 않았습니다.** 대신 상품 관리의 **아임웹에서 가져오기**에서 공개 사이트맵과 상점 목록의 상품을 선택해 상품명·가격·설명·사진을 한 번에 가져올 수 있습니다. **선택한 새 상품 한 번에 가져오기**는 사진 복사 후 비공개 상품을 바로 저장하고, 기존 상품은 건너뜁니다. 개별 원본 확인에서 **이 상품으로 편집 시작**을 사용하는 경우에는 마지막에 **상품 저장**을 눌러야 합니다. 목록에 없는 상품만 선택적으로 주소를 입력합니다. 숨김 상품·실시간 재고·옵션은 가져오지 않으며, 가져온 가격은 자동 갱신되지 않습니다. 상세 절차와 제한은 [아임웹 상품 가져오기](imweb-import.md)를 참고하세요.

## 완성된 상세이미지와 펜 페이지

언프레임 펜의 디자인은 `/shop-preview/unframe-pen`에서 확인합니다. 아임웹의 `/shop/?idx=4`는 옵션 선택과 결제를 진행하는 원본 상품 페이지로, 언프레임의 상세페이지 디자인을 그 주소에 덮어쓰는 기능은 아닙니다. 관리자 목록의 **상세페이지 보기**와 **저장된 상세페이지 보기**는 언프레임 화면을 엽니다.

사용자가 지정한 펜 상세페이지 PNG 세 장 자체를 R2에 저장하고, 기존 상품 사진 두 장은 보관한 채 이미지 목록에 추가합니다. 이 화면은 시안을 HTML 문구나 비슷한 사진 배치로 재구성하는 방식이 아닙니다. **완성 상세이미지로 표시**한 이미지가 있으면 해당 이미지들만 저장 순서대로 연결해 보여주며, 기존 사진 기반 HTML 상세 구성을 대신합니다. 각 이미지는 자르지 않고 원본 비율을 유지하며 최대 너비 887px 안에서 화면에 맞게 줄어듭니다. 기존 사진을 삭제하거나 R2에서 지우지 않습니다.

이미지에 그려진 메뉴·재생 표시·글자는 이미지의 일부입니다. 실제 메뉴나 동영상 기능으로 작동하지 않습니다. 실제 구매 동작은 이미지 아래의 구매 영역과 마지막 상세이미지 위의 구매 링크가 담당합니다. 유효한 HTTPS 구매 주소가 있을 때만 해당 주소로 연결하며, 옵션·수량·결제는 아임웹에서 진행합니다. 상품명과 저장된 설명은 화면 읽기 도구를 위한 텍스트로도 제공합니다. 완성 상세이미지가 없는 상품은 기존 사진·문구 기반 상세 구성을 사용합니다.

## 편집과 저장

상품 목록에서 **수정**을 누르거나 **상품 추가**로 새 상품을 만듭니다. 빈 목록에서는 **언프레임 펜 초안 만들기**도 사용할 수 있습니다. 이 초안 생성 동작 자체가 운영 사진을 자동 복제하지는 않습니다.

관리 필드는 상품명(필수), 첫 화면 핵심 문구, 사용 장면 소개, 제품 디테일 설명, 패키지·구성 소개, 가격 표시 문구, 아임웹 상품 상세페이지 주소, 본체 색상 안내, 상품 사양·구매 전 확인, 노출 순서(필수)입니다. 노출 순서는 0~1,000,000 사이 정수입니다. 소개란은 첫 줄을 소제목, 다음 줄부터를 설명으로 표시합니다. 가격 문구는 안내용 텍스트이며 결제 금액을 설정하지 않습니다.

사진 업로드와 입력이 끝나면 **상품 저장**을 눌러 반영합니다. **저장된 상품 미리보기**는 마지막으로 저장한 내용을 표시하므로 저장하지 않은 입력은 보이지 않습니다. 사진 업로드가 완료되어도 상품을 저장해야 이미지 목록 변경이 반영됩니다. 저장하지 않은 변경 상태에서 목록으로 돌아가거나 페이지를 나갈 때 확인을 요청하며 업로드·저장 중에는 관련 조작을 잠급니다.

## 사진 순서와 제한

완성된 상세페이지 파일을 올릴 때 **완성된 상세페이지 이미지로 추가**를 먼저 체크합니다. 이미 올린 사진은 각 사진의 **완성 상세이미지로 표시**를 체크하거나 해제해 용도를 바꿀 수 있습니다. **앞으로** 버튼으로 표시 순서를 바꾸고 사진 설명을 입력한 뒤 **상품 저장**을 누르세요. 체크된 이미지가 한 장이라도 있으면 체크된 이미지만 원본 비율로 이어서 표시합니다. 체크되지 않은 원본 사진은 목록에 보관되지만 상세 화면에 중복 표시되지 않습니다.

완성 상세이미지가 없는 경우에는 기존 사진 배치를 사용합니다.

1. 첫 번째 사진: 대표 화면과 본체 색상 영역에 표시하며, 제품 디테일에는 부분 확대하여 표시합니다.
2. 두 번째 사진: 패키지 영역에 표시합니다.
3. 세 번째 이후 사진: 추가 사진 영역에 표시합니다.

사진은 최대 12장, JPG·PNG·WebP, 실제 운영에서는 파일당 10MB 이하입니다. 사진 설명에는 이미지 내용을 구체적으로 적어주세요. 내부적으로 `product-detail-images.js`가 기존 이미지 `alt` 값의 `[DETAIL] ` 접두어로 상세이미지 용도를 기록합니다. 설명 입력창과 화면의 대체 설명에는 접두어가 노출되지 않습니다. 접두어를 포함한 저장 길이는 기존 1,000자 제한을 지키며, 별도 Firestore 필드나 권한 규칙을 추가하지 않습니다.

**목록에서 제거**한 뒤 상품을 저장하면 상품의 이미지 목록에서 빠집니다. 상품 삭제도 상품 문서를 삭제하는 동작이며 R2 사진 파일은 보관됩니다. 실제 파일을 영구 삭제하는 기능은 이 화면에 없습니다.

## 샘플 체험과 실제 운영의 구분

샘플 모드는 실제 Firebase 인증이나 Firestore·R2 저장을 수행하지 않습니다. 상품 정보와 사진 데이터는 해당 브라우저의 로컬 저장소에만 보관되며 파일당 2MB 이하입니다. 전체 브라우저 저장 용량을 초과하면 저장 오류가 표시될 수 있으므로 사진 크기를 줄여주세요. 샘플에서 만든 상품은 실제 운영 데이터로 자동 이전되지 않습니다.

실제 운영 데이터나 이미지를 열지 못하면 관리자 계정 권한과 Firebase·이미지 Worker 연결을 확인한 후 다시 시도합니다. 비공개 미리보기 링크를 전달하더라도 수신자가 승인된 직원이 아니면 내용을 볼 수 없습니다.
