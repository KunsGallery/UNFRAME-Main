# 비공개 상품 관리와 펜 상세 미리보기

이 기능은 승인된 관리자가 상품 소개를 저장하고 검토하는 비공개 도구입니다. 공개 쇼핑몰 게시 기능은 없습니다. 상품을 저장해도 일반 방문자에게 공개되지 않습니다.

## 진입과 권한

- 상품 관리: `/admin?tab=products`
- 저장된 상품 상세 미리보기: `/shop-preview/:id`
- 기본 펜 미리보기: `/shop-preview/unframe-pen`

실제 운영에서는 Google 로그인 후 승인된 관리자 권한이 필요합니다. 이메일 인증을 완료한 계정에 대해 `staffEmails/{email}` 문서의 `active: true` 및 일치하는 `email` 값을 확인합니다. Firebase 프로젝트는 기존 `unframe-main`, 웹 앱은 `1:1003147136936:web:ae4a2bd6ec1ca8ade7179d`를 사용합니다. 상품 문서는 Firestore `products/{id}`에 저장하며 읽기·생성·수정·삭제 모두 승인된 직원에게만 허용합니다.

상품 사진은 기존 비공개 R2 저장소의 `products/{상품 ID}/{UUID}.{jpeg|png|webp}` 경로를 사용합니다. 이미지 Worker는 상품 사진 요청에서도 직원 인증을 검사합니다. 미리보기는 인증된 요청으로 사진을 받아 브라우저 임시 URL로 표시합니다. 페이지의 검색 제외 설정만으로 보호하는 방식이 아닙니다.

## 기본 펜과 구매 연결 상태

운영 데이터의 `products/unframe-pen`에 언프레임 펜 소개와 실제 제품·패키지 사진 두 장을 저장했습니다. 가격은 입력하지 않았으며, 확인되지 않은 심 굵기·잉크 색상·크기·소재·판매 구성은 확인 대기로 남깁니다. 본체 색상 안내를 잉크 색상으로 해석하지 마세요.

실제 아임웹 상품 상세 URL은 사용자 제공 대기입니다. 현재 구매 주소는 비어 있으므로 구매 버튼은 **구매 주소 연결 대기** 상태로 비활성화됩니다. 확정된 상품의 전체 `https://` 주소를 입력하고 저장하면 새 창으로 해당 상품을 엽니다. 옵션·수량·재고·주문·결제·배송·교환·반품은 아임웹에서 관리하고 최종 확인합니다.

**아임웹 API 연결 및 자동 상품 동기화는 구현하지 않았습니다.** 현재 연동 범위는 관리자가 입력한 구매 주소로 이동하는 링크입니다.

## 편집과 저장

상품 목록에서 **수정**을 누르거나 **상품 추가**로 새 상품을 만듭니다. 빈 목록에서는 **언프레임 펜 초안 만들기**도 사용할 수 있습니다. 이 초안 생성 동작 자체가 운영 사진을 자동 복제하지는 않습니다.

관리 필드는 상품명(필수), 첫 화면 핵심 문구, 사용 장면 소개, 제품 디테일 설명, 패키지·구성 소개, 가격 표시 문구, 아임웹 상품 상세페이지 주소, 본체 색상 안내, 상품 사양·구매 전 확인, 노출 순서(필수)입니다. 노출 순서는 0~1,000,000 사이 정수입니다. 소개란은 첫 줄을 소제목, 다음 줄부터를 설명으로 표시합니다. 가격 문구는 안내용 텍스트이며 결제 금액을 설정하지 않습니다.

사진 업로드와 입력이 끝나면 **상품 저장**을 눌러 반영합니다. **저장된 상품 미리보기**는 마지막으로 저장한 내용을 표시하므로 저장하지 않은 입력은 보이지 않습니다. 사진 업로드가 완료되어도 상품을 저장해야 이미지 목록 변경이 반영됩니다. 저장하지 않은 변경 상태에서 목록으로 돌아가거나 페이지를 나갈 때 확인을 요청하며 업로드·저장 중에는 관련 조작을 잠급니다.

## 사진 순서와 제한

1. 첫 번째 사진: 대표 화면과 본체 색상 영역에 표시하며, 제품 디테일에는 부분 확대하여 표시합니다.
2. 두 번째 사진: 패키지 영역에 표시합니다.
3. 세 번째 이후 사진: 추가 사진 영역에 표시합니다.

사진은 최대 12장, JPG·PNG·WebP, 실제 운영에서는 파일당 10MB 이하입니다. **앞으로** 버튼으로 순서를 앞당기고 사진 설명을 입력할 수 있습니다. 일반 사진은 원본 비율을 유지하며, 부분 확대 영역에는 확대임을 명시합니다. 사진 설명은 이미지의 내용을 구체적으로 적어주세요.

**목록에서 제거**한 뒤 상품을 저장하면 상품의 이미지 목록에서 빠집니다. 상품 삭제도 상품 문서를 삭제하는 동작이며 R2 사진 파일은 보관됩니다. 실제 파일을 영구 삭제하는 기능은 이 화면에 없습니다.

## 샘플 체험과 실제 운영의 구분

샘플 모드는 실제 Firebase 인증이나 Firestore·R2 저장을 수행하지 않습니다. 상품 정보와 사진 데이터는 해당 브라우저의 로컬 저장소에만 보관되며 파일당 2MB 이하입니다. 전체 브라우저 저장 용량을 초과하면 저장 오류가 표시될 수 있으므로 사진 크기를 줄여주세요. 샘플에서 만든 상품은 실제 운영 데이터로 자동 이전되지 않습니다.

실제 운영 데이터나 이미지를 열지 못하면 관리자 계정 권한과 Firebase·이미지 Worker 연결을 확인한 후 다시 시도합니다. 비공개 미리보기 링크를 전달하더라도 수신자가 승인된 직원이 아니면 내용을 볼 수 없습니다.
