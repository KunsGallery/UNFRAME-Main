# 영문판 운영 안내

공개 페이지는 `/en`으로 시작하는 주소에서 영어로 보입니다. 예: `/exhibition/abc` → `/en/exhibition/abc`. 관리자와 작가 업로드 화면은 한국어 그대로입니다.

## 대상 페이지

메인, 전시 목록, 전시 상세, 프로젝트, 소개, 버추얼 갤러리.

상품 미리보기(관리자 전용)와 프로젝트 시안 페이지(`project-scroll`, `project-lab`)는 한국어로 둡니다.

## 언어 선택

- 공개 페이지 우상단의 `한국어 / English` 선택으로 같은 페이지의 다른 언어판으로 이동합니다.
- 고른 언어는 브라우저에 기억됩니다. 언어 없는 메인(`/`)으로 다시 오면 기억된 언어로 이동합니다.
- 다른 페이지의 한국어 링크는 그대로 한국어로 열립니다.

## 고정 문구 고치기

- 메뉴, 버튼, 안내문 같은 고정 문구는 모두 `site/js/i18n-dict.js` 한 파일에 있습니다.
- 한 줄에 한 문구씩, 한국어(`ko`)와 영어(`en`)가 나란히 있습니다. 영어만 고치면 됩니다.
- `{title}`처럼 중괄호로 된 부분은 실제 값이 들어가는 자리이니 그대로 두세요.
- 영문 페이지는 사이트를 올릴 때(`npm run build`) 자동으로 만들어집니다.

## 직접 입력하는 내용의 영문

관리자 편집 화면의 한국어 칸 아래에 **영문 (선택)** 칸이 있습니다. 비워두면 영문 페이지에서도 한국어가 보입니다.

| 화면 | 영문 칸 |
|---|---|
| 전시 편집 | 제목, 짧은 소개, 전시 소개, 장소, 관람 시간 |
| 프로젝트 소식 · 추가 슬라이드 | 제목, 짧은 소개 |
| 버추얼 갤러리 설정 | 갤러리 제목, 갤러리 소개, 작가 소개(작가 갤러리만) |
| 버추얼 갤러리 작품 | 재료, 작품 설명 (영문 제목 칸은 원래 있습니다) |

- 작가명, 주소, 가격, 이미지 설명은 입력한 그대로 보입니다.
- 작가 업로드 화면에는 영문 칸이 없습니다. 승인한 뒤 관리자 화면에서 입력해주세요.
- 수정본을 승인해도 관리자가 넣은 작품 영문 설명은 유지됩니다.

## 새 공개 페이지를 추가할 때

1. HTML의 고정 문구 요소에 `data-i18n="키"`를 붙입니다. 속성은 `data-i18n-attr="alt:키"` 형식으로 붙입니다. 입력 내용이 들어갈 자리에는 `data-i18n-content`를 붙입니다.
2. 스크립트 문구는 `t('키')`로, 입력 내용은 `localized(item,'title')`로, 내부 링크는 `localHref('/경로')`로 씁니다.
3. 페이지를 `site/scripts/i18n-html.mjs`의 `PUBLIC_PAGES`와 `I18N_READY`에 추가합니다. 스크립트는 `site/tests/i18n-scripts.test.mjs`의 `PUBLIC_MODULES`에 추가합니다.
4. `npm test`를 실행하면 영문 페이지에 번역하지 않은 한국어가 남았는지 검사합니다.
