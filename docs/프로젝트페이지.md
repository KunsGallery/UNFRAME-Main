# 프로젝트 페이지

공개 경로 `/project`. 방문자는 로그인 없이 네 프로젝트를 소개하는 포스터와 글을 보고 외부 프로젝트 사이트로 이동합니다.

사용자 확인: UP·음·U#·U.A.U 네 프로젝트를 균형 있게 소개.

기존 UNFRAME의 크림색과 파란색, 편집 디자인을 확장했습니다. 첫 화면은 네 포스터의 동일 비중 인덱스이고, 이후 각 프로젝트의 이미지와 소개를 교차 배치합니다. 고정 바로가기 메뉴, 현재 프로젝트 표시, 모바일 2열 인덱스와 1열 상세 소개, 키보드 초점 및 동작 줄이기 설정을 지원합니다.

원본 `references/project-original.html`을 보존했습니다. 이미지 네 개는 원본 Imweb 공식 자산을 가져와 WebP로 최적화했습니다. 전시 이미지 업로드는 기존 R2 연결을 사용하고, 이 페이지의 고정 브랜드 포스터는 사이트 자산으로 배포합니다. 프로젝트 관리 기능을 전시 관리자에 추가하지 않았습니다.

프로젝트 내용과 연결 주소는 `site/js/projects.js`에서 수정합니다. UP은 원본 데스크톱의 https://up.unframe.kr을 사용합니다. 원본 모바일 UP 주소는 /playlist로 달랐습니다. 다른 연결은 원본의 podcast, magazine.unframe.kr, /UAU를 유지합니다. 외부 사이트의 콘텐츠는 이번 작업 범위에 포함되지 않습니다.

메인과 공통 메뉴의 PROJECT를 `/project`에 연결하고, 메인의 기존 예시 프로젝트 설명도 제공된 실제 프로젝트 소개로 교체했습니다.
