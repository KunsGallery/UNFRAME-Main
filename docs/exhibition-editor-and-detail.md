# 전시 편집과 상세 페이지

## 디자인 방향

기존에 참고한 White Cube의 명확한 정보 구분과 Hauser & Wirth의 작품 중심 정보 구조를 UNFRAME의 크림색·파란색, 넉넉한 여백, 정제된 타이포그래피에 적용한다. 공개 상세는 작품을 감상하는 흐름, 관리자 화면은 빠르게 입력하고 검토하는 흐름을 우선한다.

대표 이미지를 자르지 않고 크게 보여준 뒤 제목·참여 작가·기간을 배치한다. 전시 소개는 읽기 편한 폭과 문단 간격을 유지하고, 데스크톱 관람 안내는 옆에서 따라온다. 전시 사진은 첫 장을 넓게, 이후 사진은 두 장씩 보여주며 모바일에서는 한 열로 전환한다. 소개·사진·관람 안내 바로가기와 사진 확대를 제공한다. 저장 전 미리보기는 공개 상세와 같은 렌더러와 스타일을 사용하며 미저장 상태를 상단에 안내한다.

## 다섯 가지 변경 사항

1. **입력 조건 표시:** 제목, 시작일, 종료일, 장소, 노출 순서는 임시 저장에도 필수다. 노출 순서의 기본값은 0이다. 전시 소개와 대표 이미지는 게시할 때 필수이며 나머지 콘텐츠 항목은 선택으로 표시한다.
2. **입장 정보 제거:** 편집 화면과 공개 상세에서 입장 정보를 표시하지 않는다. 기존 데이터 구조와 호환하기 위해 `admission` 키는 빈 값으로 저장한다. 이 변경으로 Firebase 보안 규칙을 변경하지 않는다.
3. **장소 선택:** `언프레임 - (UNFRAME)`, `쿤스갤러리 - (Kün's Gallery)`, `직접 입력` 중 선택한다. 직접 입력일 때만 장소 입력칸을 표시하고 필수로 처리한다. 기존 사용자 지정 장소는 직접 입력으로 불러와 유지한다.
4. **사진 편집 압축:** 사진 목록을 작은 썸네일 그리드로 표시한다. 그리드의 최대 높이는 데스크톱 400px, 모바일 310px이며 넘치면 내부에서 스크롤한다. 사진을 누르면 선택한 한 장의 설명·캡션·순서·제거만 편집한다.
5. **상세와 미리보기 개선:** 대표 이미지, 제목과 작가, 소개와 관람 안내, 사진의 순서로 정보 위계를 정리한다. 공개 페이지와 직원 미리보기를 함께 유지해 편집 결과를 확인하기 쉽게 한다.

## 직원 사용 순서

1. 관리자 전시 목록에서 새 전시를 등록하거나 기존 전시를 수정한다.
2. 필수 기본 정보를 입력하고 장소를 선택한다. 외부 장소라면 직접 입력을 선택한다.
3. 공개하려면 전시 소개와 대표 이미지를 준비한다. 참여 작가, 짧은 소개, 관람 시간, 주소, 지도·예약 링크는 필요할 때 입력한다.
4. 전시 사진을 추가하고 썸네일을 눌러 설명과 캡션을 작성한다. 앞으로·뒤로 이동 버튼으로 순서를 바꾸거나 목록에서 제거한다. 사진 편집 창을 닫아도 변경 내용은 아직 저장 전 상태다.
5. 저장 전 미리보기에서 상세 구성과 사진 확대를 확인한 뒤 편집으로 돌아간다.
6. 임시 저장은 게시를 끄고, 공개는 게시를 켠 상태에서 **저장하기**를 누른다. 사진 설명·캡션·순서·제거도 이때 반영된다.

사진은 최대 30장, JPG·PNG·WebP 파일당 10MB 이하를 지원한다. 샘플 모드는 파일당 2MB 이하이며 변경 사항은 해당 브라우저에만 저장된다. 실제 Firebase 연결 상태에서는 승인된 직원의 변경을 연결된 서비스에 저장한다. 미리보기 자체는 공개 페이지를 갱신하지 않는다.
