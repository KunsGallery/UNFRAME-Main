# UNFRAME 홈페이지 디자인 및 운영

홈페이지(`/`)는 제공된 원래 화면 구성과 서체를 복원하고, 첫 화면만 풀화면 슬라이드로 구성합니다. 상단 공통 메뉴 아래로 이미지가 화면을 채우며 제목, 소개, 기간과 연결 링크를 보여줍니다. 이미지는 화면을 채우도록 일부 잘릴 수 있어 가로형 대표 이미지가 적합합니다.

## 페이지 구성

히어로 다음에는 현재 진행 중인 전시, 검은 바탕의 갤러리 소개, Selected Projects, 인스타그램 기록, 프로젝트·협업 문의, 공통 사업자 푸터가 이어집니다. 프로젝트는 데스크톱에서 2열, 모바일에서 1열로 표시합니다. 하단의 원래 구성과 타이포그래피를 유지하며, ABOUT 페이지는 전용 `about-shell.css`로 기존 새 디자인을 유지합니다.

현재 전시 영역은 공개된 현재 전시 중 대표 전시 한 개를 보여주고, 다른 전시는 전체 전시 페이지로 안내합니다. 현재 전시가 없으면 다음 전시 준비 안내와 전시 목록 링크를 표시합니다.

## 슬라이드 노출 기준

- 전시: 공개된 현재 전시가 자동으로 들어갑니다. 예정·종료 전시는 히어로 자동 선택 대상이 아닙니다.
- 프로젝트 이벤트: 공개 상태와 메인 노출(Featured)이 모두 선택되어 있고 종료일이 지나지 않은 항목을 표시합니다. 예정 이벤트도 저장 후 바로 노출하며, 종료일 당일까지 유지합니다.
- 버추얼 갤러리: 공개 상태와 메인 노출이 모두 선택된 항목을 표시합니다. 기간 없이 등록할 수 있으며, 기간을 설정한 경우 종료일 당일까지 유지합니다.

현재 전시가 먼저 나오고 이벤트·버추얼 갤러리는 작은 노출 순서부터 이어집니다. 같은 순서는 제목으로 정렬합니다. 날짜 판정은 서울 시간을 기준으로 합니다. 이미지 또는 연결 주소가 유효하지 않거나 이미지를 불러오지 못한 슬라이드는 제외합니다. 표시할 항목이 없으면 블루 UNFRAME / Gallery & Projects 화면과 전시 탐색 링크를 제공합니다.

## 관리자 사용법

**관리자 → 메인 슬라이드 관리 → 등록 → 공개 상태 + 메인 노출 → 저장**

1. 기존 관리자 계정으로 로그인하고 **메인 슬라이드 관리**를 엽니다.
2. **이벤트 · 버추얼 갤러리 등록**에서 종류, 제목, 소개, 연결 주소와 대표 이미지를 입력합니다. 프로젝트명과 이미지 설명도 입력할 수 있습니다.
3. 이벤트는 시작일과 종료일을 입력합니다. 버추얼 갤러리는 기간을 생략하거나 시작일·종료일을 함께 입력합니다.
4. **공개 상태로 게시**와 **메인 노출 (Featured)**을 모두 선택하고 노출 순서를 정한 뒤 **저장하기**를 누릅니다. 이미지 업로드 완료 후에도 저장해야 반영됩니다.

대표 이미지는 JPG·PNG·WebP, 10MB 이하를 사용합니다. 연결 주소는 `https://` 주소 또는 `/`로 시작하는 사이트 내부 주소를 입력합니다. 메인에서 숨기려면 메인 노출 선택을 해제하고 저장합니다. 현재 전시는 기존 전시 관리에서 공개 상태와 기간을 관리하면 자동 반영됩니다.

데모 모드는 이 브라우저에만 저장되며 실제 사이트에 반영되지 않습니다. 실제 연결에서는 기존 Firebase 프로젝트의 `homeHighlights` 데이터와 지정된 이미지 저장소를 사용합니다.

## 움직임과 접근성

슬라이드가 두 개 이상이면 8초마다 자동 전환합니다. 이전·다음 버튼, 슬라이드 선택 버튼, 현재 위치와 자동 넘김 제어를 제공합니다. 키보드 좌우 화살표로도 전환할 수 있습니다. 포인터가 히어로 위에 있거나 내부에 키보드 초점이 있을 때, 히어로가 화면 밖에 있을 때, 브라우저 탭이 숨겨졌을 때 자동 넘김을 멈춥니다.

시스템의 움직임 줄이기 설정에서는 자동 넘김을 초기 정지하고 전환·이미지 확대 애니메이션을 제거합니다. 본문 바로가기, 키보드 초점 표시와 이미지 대체 텍스트를 제공하며 비활성 슬라이드는 접근성 탐색에서 제외합니다.

## 구현 위치

공개 화면은 `site/index.html`, `site/assets/home.css`, `site/assets/home-slider.css`, `site/js/home.js`, `site/js/home-slider.js`에서 구성합니다. 슬라이드 선택 기준은 `site/js/highlight-model.js`, 관리자 화면은 `site/js/admin-highlights.js`에서 관리합니다.
