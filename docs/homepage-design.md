# UNFRAME 홈페이지 디자인

홈페이지(`/`)는 작품을 먼저 보여주는 갤러리 편집형 화면입니다. 크림색 바탕과 UNFRAME 블루, 넉넉한 여백, 얇은 구분선을 사용합니다. 한글은 Noto Sans KR, 영문 프로젝트명은 EB Garamond로 구분합니다.

## 구성과 반응형

- 히어로: 왼쪽 소개와 전시 탐색 링크, 오른쪽 대표 전시 이미지와 상태·제목·기간. 모바일에서는 세로로 배치합니다.
- 전시: 히어로와 같은 대표 전시의 이미지, 요약, 작가·장소와 상세 링크.
- 소개: 블루 바탕의 갤러리 소개와 화면 진입에 반응하는 선형 프레임.
- 프로젝트: UP, 음, U#, U.A.U의 설명과 제공된 공식 포스터, 각 프로젝트 앵커 링크.
- 기록·문의: 인스타그램 피드와 협업 문의. 공통 메뉴와 사업자 푸터를 유지합니다.

전시 이미지는 `object-fit: contain`으로 비율을 보존합니다. 프로젝트 행의 작은 포스터에는 회전과 확대 제스처를 적용합니다.

## 전시 선택과 빈 화면

기존 공개 전시 데이터에서 현재 전시를 우선 선택합니다. 현재 전시가 없으면 가장 가까운 예정 전시, 그다음 가장 최근 종료한 전시를 보여줍니다. 선택한 전시의 상태를 캡션과 전시 영역에 명시합니다.

전시가 없거나 데이터를 불러오지 못하면 UNFRAME / Gallery & Projects 브랜드 화면과 안내 문구, 전시 목록 링크를 제공합니다. 이미지가 없는 전시에서도 브랜드 화면을 유지합니다. 데모 모드와 실제 Firebase 연결의 구분은 기존 데이터 계층과 공통 안내를 따릅니다.

## 움직임과 접근성

히어로 뒤의 세 개 블루 선형 프레임이 천천히 회전·변형합니다. 포인터 이동은 작품 자체를 왜곡하지 않고 이미지와 프레임에 작은 위치 차이를 줍니다. 터치 입력에서는 포인터 반응을 사용하지 않습니다.

히어로 아래의 ‘움직임 멈추기 / 움직임 켜기’ 버튼이 프레임 반복과 포인터 깊이 효과를 제어합니다. 시스템의 움직임 줄이기 설정에서는 자동으로 정지하며 CSS 애니메이션·전환을 제거합니다. 히어로가 화면 밖에 있거나 브라우저 탭이 숨겨지면 반복 렌더링을 중단합니다. 캔버스는 장식 요소로 스크린리더에서 제외하고, 본문 바로가기·키보드 초점 표시·이미지 대체 텍스트를 제공합니다.

## 변경 범위

구현 위치는 `site/index.html`, `site/assets/home.css`, `site/js/home.js`입니다. 전시·프로젝트 상세 경로, 관리자 기능과 백엔드 구조는 기존 시스템을 사용합니다. 콘텐츠 관리 체계가 없는 프로젝트 설명은 정적 문구입니다.
