# 프로젝트 인터랙션 임시 예시

비교용 경로 `/project-lab`. 공식 `/project` 내용과 메뉴는 변경하지 않습니다. 공개 링크로 열 수 있지만 검색 색인을 막고 주 메뉴에는 연결하지 않았습니다.

- UP: 버튼으로 시작·정지하는 파형, 트랙별 소개 문장. 실제 음악 재생 없음.
- 음: 네 문장을 순환하는 대화와 응답 효과. 실제 음성 재생 없음.
- U#: 세 가지 기록 소개를 책장으로 표현. 이전/다음 버튼, 방향키, 터치 스와이프 지원.
- U.A.U: 포인터에 반응하는 연결 노드, 연결 확장 버튼. 실제 작가 명단이나 인원 수를 의미하지 않는 개념도.

소개 핵심 문장은 화면에 들어올 때 파란색으로 강조됩니다. 동작 줄이기 설정에서는 비필수 애니메이션을 제거합니다. UP 파형은 화면 밖 또는 비활성 탭에서 멈춥니다.

데스크톱·모바일 브라우저에서 네 효과의 버튼 상태, 페이지 범위, 키보드 조작, 화면 넘침, JavaScript 오류 및 동작 줄이기 설정을 확인했습니다. 적용할 효과를 사용자와 선택한 후 공식 페이지에 반영합니다.
