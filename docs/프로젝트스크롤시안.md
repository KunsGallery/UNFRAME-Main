# 프로젝트 스크롤 시안

별도 경로 `/project-scroll`. 공식 `/project` 및 이전 `/project-lab`을 유지합니다. 주 메뉴에 연결하지 않고 검색 색인을 차단했습니다.

사용자 피드백: 직접 실행하기 전 정적인 이전 시안 대신, 각 프로젝트가 화면에 딱 맞고 진입하자마자 살아 움직이는 스페셜 섹션을 원함.

## 조사한 Originkit 효과

실제 웹페이지의 설명과 프리뷰를 열어 조사했습니다. 아래는 형태와 움직임의 참고이며 원본 코드를 복사하거나 라이브러리를 설치한 구현은 아닙니다.

- UP — Scroll Wave Field: 입자 파도가 움직이는 공간. https://www.originkit.dev/components/scroll-wave-field
- 음 — Appear Text: 반복 타이포그래피와 중심 문장 드러내기. https://www.originkit.dev/components/appear-text
- U# — Floating Gallery: 이미지 지면이 속도를 달리하며 부유. https://www.originkit.dev/components/floating-gallery
- U.A.U — Particle Drift: 자동으로 흐르는 입자, 거리 기반 연결선, 포인터 주변 강조. https://www.originkit.dev/components/particle-drift?preset=base

각 효과는 기존 정적 HTML 구조에 맞게 자체 Canvas 2D/CSS로 해석했습니다. Originkit 원본의 WebGL 구현과 동일한 컴포넌트를 사용했다는 의미는 아닙니다.

## 시안 구성

네 프로젝트 각각 최소 100svh. 브라우저 기본 스크롤과 CSS scroll-snap으로 정렬하고 고정 메뉴로 직접 이동 가능. 휠 이벤트를 가로채거나 강제 스크롤 잠금을 적용하지 않습니다.

스크롤 진입 시 효과가 자동 시작합니다. 화면 밖 CSS 효과를 멈추고 활성 Canvas만 초당 약 30회 그립니다. 백그라운드 탭과 일시정지 상태에서는 업데이트를 멈춥니다. 동작 줄이기 환경에서는 정적 프레임을 표시하며 스크롤 정렬도 proximity로 완화합니다.

UP: 자동 입자 파형과 레코드/포스터 모션. 음: 반복 글자 배경, 문장 wipe, 파문. U#: 제공된 포스터와 원본 소개 문장으로 만든 지면이 서로 다른 리듬으로 부유. U.A.U: Particle Drift를 참고해 자동으로 떠다니는 점과 거리별 연결선, 마우스·터치 주변 파란색 강조로 교체. 모바일 65개/데스크톱 115개로 입자 수를 제한. 실제 음악 및 음성 재생 없음. 책 지면은 실제 출판물 스캔이 아닌 소개 시안으로 표시했습니다.

데스크톱 1280x720, 모바일 390x844에서 모든 섹션 높이 및 정렬, 화면 넘침 없음, 메뉴 이동, 자동 활성화 및 일시정지/재시작을 확인했습니다. 문법 검사, 기존 테스트 19개, 빌드 및 디자인 탐지 검사 통과.

Originkit의 Get this Component에는 CLI, Code, MCP, AI Prompt 옵션이 표시됩니다. 횟수 제한이 어느 기능에 적용되는지는 확인하지 못했고 원본 코드 복사·AI 프롬프트 생성·유료 기능을 실행하지 않았습니다. 정확한 일치를 위해서는 원본 코드와 base 프리셋 설정값이 가장 유용합니다.

## 추가 개선

UP의 입자 파형을 화면 전체로 확장하고 LP 라벨·홈·비대칭 표시로 회전을 눈에 띄게 변경했습니다. 음의 반복 배경은 VOICE, DIALOGUE, RESONANCE, BETWEEN, ON AIR, LISTEN으로 교체했습니다. U#은 큰 3D 펼침책과 7초 주기의 자동 책장 넘김 및 세 가지 소개 지면 순환으로 변경했습니다. 실제 출판물 스캔이 아닌 소개 시안입니다. U.A.U는 감쇠와 원래 흐름으로 복귀하는 힘을 적용해 포인터 근처 입자가 부드럽게 모이되 한 지점에 전부 쌓이지 않도록 했습니다.

## 다꾸 배경 방향

사용자는 UP 및 U.A.U 효과를 승인하여 그대로 유지했습니다. 음은 사용자가 선택한 VOICE · DIALOGUE · RESONANCE 세 단어만 배경에 사용합니다. U#은 단일 3D 책 대신 섹션 전체에 사진 조각, 전시 소개의 문장, 종이 메모, 테이프, 출판 스탬프를 배치한 다꾸 구성으로 교체했습니다. 실제 방명록·출판물 스캔을 추가한 것은 아니며 기존 공식 이미지와 소개 문장을 활용한 시안입니다. 본문은 별도의 조용한 지면에 올려 가독성을 유지했습니다. 모바일390x844에서 U# 화면 높이844, 가로 넘침 없음 및 스크립트 오류 없음 확인.
