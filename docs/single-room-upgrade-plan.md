# 싱글룸 갤러리 업그레이드 검토안

참고 자료: 사용자가 제공한 `UAU-single-room-gallery-reference.zip` (2026-10-14). README, GalleryScene, 갤러리 모델과 실제 텍스처를 현재 UNFRAME 구현과 비교한 검토안이다. 참고 패키지의 브라우저 동작은 이번 검토에서 실행하지 않았다. 이 문서는 적용 전 계획이며 운영 사이트 변경을 포함하지 않는다.

## 방향

현재 전시·작가 갤러리 연결, Google 직원 로그인, Firebase 공개 권한, R2 업로드와 작품 실측 배치를 유지하면서 렌더링의 외부 풍경과 건축 재질을 개선한다. 첫 단계에서는 현재 공간 치수도 유지한다. 참고 패키지 전체나 React 앱을 교체 도입하기보다 필요한 공간 표현을 현재 렌더러에 옮긴다.

## 가장 먼저 가져올 외부 표현

현재 외부는 자갈 바닥과 경계석, Canvas로 그린 숲을 곡면 배경에 적용한다. 참고 자료는 이미지 기반 숲 배경 앞에 실제 수평 포장 바닥, 콘크리트 플랜터, 입체 식재와 목재 측벽을 둔다. 가까운 요소의 이동 시차와 그림자가 배경 이미지의 평면성을 보완한다.

1. 제공된 woodland WebP를 기본 숲 배경으로 사용하고 현재 색감에 맞춰 밝기와 위치를 조정한다. 반복 경계와 숲 이미지에 이미 들어 있는 빛 방향을 함께 확인한다.
2. 창 바로 밖에 낮은 콘크리트 플랜터와 입체 식재, 포장 바닥을 배치한다. 포장 이음매와 창턱의 매립 그레이팅을 실제 바닥 방향에 맞춘다.
3. 목재 측벽과 배경 가장자리 가림을 사용해 방 끝에서 숲 이미지의 경계가 드러나지 않도록 한다.
4. 창틀의 얇은 구조와 약한 유리 표현, 자연광 그림자와 접촉 그림자를 조정한다. 작품 색과 실내 가독성을 우선한다.

## 더 발전시킬 부분

- 깊이: 가까운 식재는 3D, 중간 거리에는 제한된 줄기·수목 요소, 먼 풍경은 이미지로 나눈다. 배경 한 장을 카메라 반대 방향으로 움직여 깊이처럼 보이게 하는 연출은 피한다.
- 분위기: 잎 끝의 아주 작은 움직임과 은은한 그림자 변화를 선택적으로 적용한다. 화면 전체가 출렁이는 움직임은 넣지 않는다. 움직임 줄이기 설정에서는 정적으로 표시한다.
- 재질: plaster, 목재, 포장, 콘크리트의 거칠기와 미세 요철을 이식한다. 새틴 우레탄은 기존 바닥 선택을 보존하면서 추가 후보로 검토한다.
- 작품: 캔버스 측면의 자연색·검정·이미지 감싸기, 선택 가능한 두께는 다음 단계 후보다. 작품의 세로·가로 cm는 그대로 유지한다.
- 조명: 전체 조명과 작품 중심 조명, 광천장은 외부 개선 이후 단계적으로 도입한다. 외부 밝기와 실내 조명을 분리하되 관리자에게는 간단한 선택과 조절값만 보여준다.
- 성능: 참고 코드의 14,000개 잎 인스턴스와 높은 그림자 해상도를 그대로 기본값으로 옮기지 않는다. 기기별 식재 밀도와 그림자 품질을 시험하고, 화면 밖·숨겨진 탭의 렌더 비용을 줄인다. 모바일에서도 작품 목록 대체 관람을 유지한다.

## 그대로 가져오지 않을 부분

참고 코드의 고정 작품 면 크기와 size 배율, 6·9점 중심의 슬롯 배치, IndexedDB 저장과 샘플 작품, 참고용 작품 상세 창은 현재 시스템을 대체하지 않는다. 정방형 12×12m·롱형 9×18m 공간도 첫 단계에서는 적용하지 않는다. 공간 형태를 추가할 경우 기존 작품의 실제 치수로 수용 여부를 먼저 검증하고, 배치를 확인한 뒤 저장하는 별도 작업으로 진행한다.

참고 패키지는 React 및 Three.js 0.185.1을 사용하고 현재 갤러리는 기존 Three.js r128 기반이다. 텍스처 색공간과 재질 옵션 등을 현재 버전에 맞게 변환해야 하며, 최신 렌더러 전환은 별도 범위로 검토한다.

## 적용 순서와 완료 기준

**1차:** 현재 방과 관리 시스템을 유지하고 숲 텍스처, 포장·플랜터·식재·측벽, 유리·창틀·자연광을 개선한다. 동일한 작품을 가진 기존·개선 공간을 비교해 확인한다.

**2차:** 필요하면 실내 재질·조명·캔버스 측면 선택을 관리자 설정으로 확장한다. 신규 설정은 기존 갤러리에 기본값을 제공하며 Firebase 규칙도 함께 갱신한다.

**3차:** 다른 방 형태, 숲의 계절 프리셋과 깊이 표현을 확장한다. 각 방의 실측 벽 공간을 기준으로 배치 검증을 다시 설계한다.

완료 기준: 창 가까이와 양 끝에서 배경 경계가 드러나지 않을 것, 움직이며 가까운 요소의 시차가 자연스러울 것, 작품 치수·비율·색을 유지할 것, 작가별 작품·업로드·공개 권한과 관람 링크를 유지할 것, 외부 표시를 끈 상태도 정상일 것, 데스크톱과 모바일에서 성능과 입력·상세 창·복귀 동작을 확인할 것.
