# 전시·작품 공유 카드

공개된 전시와 작품의 이미지·등록 정보를 재사용해 방문자가 공유용 PNG를 만들 수 있습니다. 별도 로그인이나 관리자 입력은 필요하지 않습니다.

## 어디에서 사용하나요?

- 공개 전시 상세 페이지의 **공유 카드 만들기** 버튼
- 전시의 ‘참여 작가 · 대표작’ 진열대에서 작품을 선택한 뒤 **작품 공유 카드** 버튼
- 공개 버추얼 갤러리에서 작품 상세를 연 뒤 **작품 공유 카드** 버튼

관리자 전시 미리보기와 버추얼 갤러리의 관리자 미리보기에는 공유 카드 진입 버튼을 제공하지 않습니다. 버추얼 갤러리의 공개 작품 공유는 부모 전시와 해당 갤러리가 모두 공개된 경우에만 제공됩니다. 이 기능은 기존 공개 상태를 변경하지 않습니다.

## 디자인과 이미지 크기

| 선택 | 구성 |
| --- | --- |
| A · 작품 전체형 | 크림 지면과 블루 UNFRAME 표기. 이미지 전체를 원래 비율로 배치하고 정보를 분리합니다. 세로형은 이미지 아래, 가로형은 오른쪽에 정보가 놓입니다. |
| B · 이미지 몰입형 | 이미지를 카드 전체에 채우고 어두운 그라데이션 위에 흰색 정보를 올립니다. 카드 비율에 따라 이미지 가장자리가 잘릴 수 있습니다. |

두 디자인 모두 다음 규격을 선택할 수 있습니다.

- **스토리 · 9:16:** 1080 × 1920px
- **가로형 · 4:3:** 1200 × 900px

화면 미리보기는 화면에 맞게 축소되지만 저장 파일은 위 규격의 PNG입니다. 긴 제목·작가명·정보는 제한된 줄 수 안에서 줄바꿈하고 넘치는 부분은 말줄임합니다.

전시 카드는 대표 이미지, 전시명, 작가, 기간과 장소를 사용합니다. 작품 카드는 해당 작품 이미지, 작품명, 작가, 부모 전시명과 등록된 제작연도·재료를 사용합니다. 없는 정보는 임의로 생성하지 않습니다. 이미지를 새로 생성하거나 작품 자체를 수정하는 기능은 아닙니다.

## 저장과 공유

1. 디자인과 비율을 고릅니다.
2. 미리보기가 완성되어 ‘저장 준비 완료’가 표시되면 **PNG 이미지 저장**을 누릅니다.
3. 파일 공유를 지원하는 기기·브라우저에서는 **기기에서 공유**도 표시됩니다.
4. **링크 복사**는 전시 상세 주소를 복사합니다. 작품 카드의 링크도 부모 전시 상세로 연결됩니다.

인스타그램에 자동으로 게시하지 않습니다. 저장한 이미지를 스토리 등에 직접 업로드하고, 필요한 링크는 별도로 붙여넣습니다. 이미지에 클릭 가능한 링크가 내장되거나 QR이 생성되지는 않습니다. 이미지가 준비되지 않으면 저장 버튼은 비활성화되고 오류 안내가 표시됩니다.

## 운영과 구현 범위

관리자는 기존 전시·작품 관리에서 이미지와 정보를 수정하면 됩니다. 공유 카드 전용 데이터 입력, Firestore 필드·규칙 변경, 외부 이미지 생성 서비스는 추가하지 않았습니다. 생성은 방문자의 브라우저에서 이루어지며 PNG를 서버에 저장하지 않습니다. 실제 Firebase/R2 연결과 로컬 데모의 구분은 유지합니다.

구현은 `site/js/share-card.js`, 스타일은 `site/assets/share-card.css`에 있습니다. 공개 전시 상세, 작품 진열대, 버추얼 갤러리의 작품 상세가 같은 생성기를 사용합니다.
