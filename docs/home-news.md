# UNFRAME JOURNAL 관리

관리자 로그인 후 **프로젝트 소식 · 추가 슬라이드**에서 새 소식·이벤트를 등록하거나 기존 항목을 수정합니다. 프로젝트 소식(발행·에피소드 등)은 기간 없이 등록할 수 있습니다. 이벤트는 게시할 때 시작일과 종료일이 필요합니다.

제목은 필수이며 공개 게시에는 대표 이미지와 연결 주소가 필요합니다. 소식 또는 UNFRAME JOURNAL 노출에는 프로젝트명 UP, 음, U#, U.A.U 중 하나를 선택합니다. 대표 이미지 업로드는 기존 Cloudflare R2 경로를 사용합니다. 가로형 16:9, 1920 × 1080 px 이상의 사진을 권장하며 다른 크기도 업로드할 수 있습니다. 히어로와 카드에서는 가장자리가 잘릴 수 있으므로 중요한 피사체는 중앙에 배치합니다. 연결 주소는 /project#up 같은 내부 주소 또는 https://로 시작하는 실제 소식 페이지 주소입니다. 주소만으로 이미지를 자동 생성하지 않습니다.

**공개 상태로 게시**를 선택하고 **UNFRAME JOURNAL 노출**을 선택해 저장합니다. 목록에서도 UNFRAME JOURNAL 선택을 바로 바꿀 수 있습니다. **히어로 슬라이드 노출**은 독립적인 선택입니다. 기존 JOURNAL 선택은 그대로 유지되며 내부 저장 필드 `nowFeatured`도 바뀌지 않습니다. 버추얼 갤러리는 히어로 선택만 가능합니다. 기존 이벤트는 JOURNAL에 추가하려면 네 프로젝트 중 하나를 지정합니다.

공개·선택된 소식과 이벤트 중 종료되지 않은 항목을 작은 노출 순서부터 최대 3개 표시합니다. 같은 크기의 카드로 나란히 표시하며 모바일에서는 세로로 쌓습니다. 동순위는 제목순으로 정렬하므로 대표 소식은 가장 작은 순서로 지정합니다. 등록된 소식이 없으면 준비 안내와 프로젝트 링크를 표시합니다. 직원 두 계정만 저장하며 방문자는 로그인 없이 열람합니다.

샘플 체험은 브라우저에만 저장되며 운영 Firebase 데이터로 전송되지 않습니다.

전시는 이 메뉴에 중복 등록하지 않습니다. 전시 관리에서 공개한 현재 전시는 등록된 대표 이미지·제목·기간으로 히어로에 자동 표시됩니다. 종료일 다음 날부터 자동 제외되므로 실제 전시 기간을 입력해야 합니다.
