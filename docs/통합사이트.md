# 통합 사이트 변경

메인과 전시를 하나의 배포 단위인 `site/`로 합쳤습니다. 기존 파일명 exhibition 폴더는 site로 변경했습니다. 원본은 references에 각각 보존했습니다.

메인의 전시 영역과 /exhibition 목록은 `subscribeExhibitions`를 통해 같은 published=true 데이터를 구독합니다. 관리자에서 저장한 제목/기간/소개/대표 사진/게시 여부가 두 화면에 반영됩니다. 운영 모드는 Firestore onSnapshot, 샘플 모드는 탭 사이 저장 이벤트를 사용합니다. 한국 날짜 변경은 두 모드 모두 분 단위로 다시 확인해, 열린 메인과 목록에서도 시작/종료에 따른 전시 분류를 갱신합니다.

첨부 메인의 히어로와 3D 모션, 현재 전시 소개, 매니페스토, 프로젝트 소개, 인스타그램, 문의, 실제 제공된 사업자/운영 정보와 푸터를 보존했습니다. 모바일 확대 제한을 제거하고 콘텐츠가 넘치지 않도록 고정 화면 높이를 완화했습니다. 3D는 기존 고밀도 geometry 대신 제한된 면 수와 픽셀 비율을 사용하고 화면 밖/백그라운드에서 렌더링을 중단합니다. 모션 감소 설정에서는 제목만 표시합니다.

프로젝트 소개 문구는 첨부 원본의 정적 콘텐츠입니다. 프로젝트 상세 페이지나 프로젝트 CMS는 아직 만들지 않았습니다. 문의 버튼은 원본의 빈 링크 대신 원본에 제공된 전화번호로 연결했습니다. 이메일이나 문의 저장 서버는 임의로 만들지 않았습니다.

인스타그램 위젯은 원본 LightWidget 주소를 유지했습니다. 위젯 콘텐츠/계정/구독 상태는 외부 서비스에서 관리되며, 현재 실제 피드가 정상 반환되는지는 확인되지 않았습니다. 공식 인스타그램 바로가기 링크를 제공합니다. 원본의 @unframe.k 표기는 원본 하단 SNS 링크의 unframe.kr 기준으로 일치시켰습니다.

ABOUT/PROJECT 메뉴는 메인 내 섹션, EXHIBITION은 /exhibition, JOIN은 기존 join.unframe.kr로 연결합니다. SHOP/U.A.U/약관/개인정보 페이지는 현재 아임웹 공식 URL을 유지합니다. 메인 도메인 이전 전에는 이 경로들을 구현하거나 유지되는 별도 아임웹 주소를 제공해야 합니다. 도메인 설정과 기존 아임웹 사이트는 변경하지 않았습니다.

이전 /exhibitions/:id 상세 주소는 /exhibition/:id로 301 이동합니다. 메인, 목록 및 상세는 동일 메뉴/사업자 푸터를 사용합니다. 관리자는 작업용 메뉴를 사용합니다. Google 관리자 권한과 서버 보안 규칙은 기존 구현을 유지합니다.
