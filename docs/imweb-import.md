# 아임웹 공개 상품 가져오기

아임웹에 등록한 공개 상품을 읽어 언프레임의 비공개 상세페이지 편집 초안으로 가져옵니다. 사용자는 아직 공식 API 키를 발급하지 않았으므로 이 기능은 공식 상품 API 연결이나 자동 동기화가 아닙니다. 관리자만 실행할 수 있으며, 가져와 저장한 상품도 일반 방문자에게 공개되지 않습니다.

## 여러 상품을 한 번에 가져오기

1. 승인된 Google 계정으로 `/admin?tab=products`에 들어가 **아임웹에서 가져오기**를 누릅니다.
2. 상점 첫 카테고리뿐 아니라 공개 사이트맵의 상품 주소도 조회해 목록을 구성합니다. 확인된 공개 상품은 펜, 작품 두 점, 예약금 상품의 네 개입니다. 목록의 상품 종류를 확인하고 가져오지 않을 항목은 선택을 해제하세요.
3. **선택한 새 상품 한 번에 가져오기**를 누릅니다. 새 상품은 기본 선택되며 이미 등록된 상품은 선택할 수 없습니다.
4. 선택한 각 상품의 설명과 앞의 최대 12장 사진을 가져와 R2에 복사하고 **비공개 상품으로 바로 저장**합니다. 이 경로는 별도의 최종 저장 버튼을 누르지 않습니다.
5. 상품 관리로 돌아가 **상세페이지 보기**로 결과를 확인하거나 **수정**에서 문구와 사진 순서를 다듬습니다. 편집한 변경 사항은 **상품 저장**으로 반영합니다.

상품별 성공·실패를 따로 표시합니다. 한 상품이 실패해도 나머지 상품을 계속 처리하고 성공한 상품은 유지합니다. 다시 시도할 때 이미 가져온 상품은 건너뜁니다. 동일한 ID를 다른 세션에서 동시에 등록한 경우에도 새 상품 생성 전용 트랜잭션으로 기존 상품을 덮어쓰지 않습니다.

## 개별 원본 확인과 선택 가져오기

목록의 **가져오기** 또는 **원본 확인**으로 상품 하나의 원본과 사진을 검토할 수 있습니다. 목록에서 찾을 수 없는 경우에만 **목록에서 찾을 수 없는 상품만 주소로 추가**를 열고 `https://unframe.imweb.me/shop/?idx=4` 같은 전체 주소를 입력합니다. 모든 상품의 주소를 각각 입력할 필요는 없습니다.

개별 흐름에서는 새 상품의 앞의 최대 6장 사진을 기본 선택하고, 기존 상품 사진은 기본 선택하지 않습니다. 사진을 선택해 **이 상품으로 편집 시작**을 누르면 R2 복사 후 편집 화면으로 이동합니다. 이 경로는 **상품 저장**을 눌러야 등록됩니다.

상품명과 구매 주소는 가져온 상품을 기준으로 채웁니다. 새 상품의 설명은 제품 디테일, 짧은 소개는 핵심 문구의 초안이 됩니다. 원본 상세페이지의 디자인·스크립트·영상·옵션 UI를 복제하는 기능은 아닙니다. 가져온 설명은 실행되지 않는 일반 텍스트로 표시하며, 언프레임의 상세페이지 레이아웃에서 연출합니다. 원본 이미지에 포함된 글자는 이미지 그대로 남습니다.

## 기존 상품을 다시 가져올 때

아임웹 상품 번호가 같은 구매 주소 또는 `imweb-{상품 번호}` ID로 기존 상품을 찾습니다. 따라서 이미 연결된 `unframe-pen`도 새 중복 상품을 만드는 대신 기존 상품 편집으로 이어집니다. 새 가져오기 상품은 `imweb-4` 같은 고정 ID를 사용합니다.

기존 상품의 소개·연출 문구·사진은 유지합니다. 비어 있는 핵심 문구와 제품 디테일에는 원본 내용이 채워질 수 있습니다. **상품명과 가격 표시를 아임웹 원본으로 바꾸기**를 선택한 경우에만 기존 이름과 참고 가격을 교체합니다. 구매 주소는 확인한 아임웹 원본 주소로 연결하며, 선택한 새 사진은 기존 사진 뒤에 추가합니다. 사진 중복 여부를 자동 판정하거나 기존 사진을 자동 교체하지 않습니다.

## 가져오는 범위와 제한

- 상점은 `https://unframe.imweb.me`로 고정합니다. 주소 입력은 이 상점과 승인된 언프레임 도메인의 `/shop/?idx=숫자` 형태만 허용하며 실제 조회는 고정 상점에서 수행합니다.
- 목록·사이트맵·개별 상세에서 공개된 상품만 읽습니다. 사이트맵에 나타나지 않는 상품도 있을 수 있으며 숨김·회원 전용·미공개 상품은 가져오지 못합니다. 사이트맵 조회에 실패하면 현재 상점 목록으로 돌아가고 그 상태를 표시합니다. 일부 상품 상세에 접근하지 못한 경우에도 나머지 목록은 표시합니다.
- 상품명·표시 가격·짧은 소개·상세 설명 텍스트 및 확인 가능한 대표/상세 사진을 가져옵니다. 재고·옵션·수량·주문·고객 정보는 가져오지 않습니다.
- 가격은 **가져온 시점의 참고 정보**입니다. 자동 갱신되지 않으며 결제 가격을 설정하지 않습니다. 옵션·수량·최신 가격·배송·교환·반품은 연결된 아임웹 상품 페이지에서 확인하고 진행합니다.
- 사진은 이 상점 소유의 승인된 아임웹 CDN 경로에 있는 JPG·PNG·WebP만 지원합니다. 기존 사진과 합쳐 최대 12장, 파일당 10MB 이하입니다. 지원하지 않는 사진은 파일로 직접 추가하세요.
- 상점의 공개 HTML 구조가 바뀌면 추출에 실패할 수 있습니다. 상태 메시지를 확인하고 **목록 다시 불러오기**나 개별 상품 주소를 사용합니다. 비공개 상품은 주소를 입력해도 공개되지 않습니다.

## 저장과 보안

Worker의 `/imweb/products`, `/imweb/products/{번호}`, `/imweb/image`는 읽기 요청만 허용하고 매번 기존 Firebase 승인 직원 권한을 검사합니다. 원본 상점으로 로그인 쿠키나 방문자 인증을 전달하지 않고 원본 스크립트를 실행하지 않습니다. 공식 API 키나 새로운 비밀키는 필요하지 않습니다.

선택한 사진은 기존 인증 업로드 경로를 통해 `products/{상품 ID}/{UUID}.{확장자}`로 R2에 복사합니다. 상품 문서와 복사된 상품 사진은 계속 승인된 직원만 읽을 수 있습니다. 아임웹 원본 사진을 지우거나 변경하지 않습니다.

사진 복사는 상품 문서 저장 전에 발생합니다. 일괄 가져오기는 복사 후 바로 저장하며, 개별 가져오기는 편집 화면에서 최종 저장합니다. 복사 중 오류나 저장 충돌이 나거나 개별 편집을 저장하지 않고 나가면 상품 문서에 연결되지 않은 R2 파일이 남을 수 있습니다. 재시도 시 다시 복사될 수 있으며 자동 정리·자동 삭제 기능은 없습니다. 상품 이미지 제거와 상품 삭제도 R2 파일을 영구 삭제하지 않습니다.

샘플 모드는 실제 아임웹·Firebase·R2 대신 샘플 상품과 브라우저 로컬 저장소를 사용합니다. 실제 운영으로 자동 이전되지 않습니다.

## 확인 범위

사이트맵 상품 주소 추출·주소 및 이미지 제한·기존 상품 보존·직원 인증·새 상품 전용 저장 검사를 포함한 사이트 테스트 61개와 빌드를 통과했습니다. 실제 공개 상점의 네 상품 발견과 샘플 모드의 선택 일괄 가져오기 → 저장 → 상품 목록 흐름을 확인했습니다. 실제 승인 직원의 로그인 세션으로 운영 가져오기를 끝까지 실행하는 검증은 아직 수행하지 않았습니다.
