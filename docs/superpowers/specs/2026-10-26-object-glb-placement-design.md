# 오브제 · 설치 작품: GLB 업로드와 전시 자리 배치 설계

작성일: 2026-10-26 · 상태: 사용자 승인

## 목표

오브제 작가가 직접 만든 3D 파일(GLB)을 올리면, 버추얼 갤러리 안의 정해진 **전시 자리**에 실제 크기로 세운다. AI 자동 3D 생성은 범위에서 제외한다(보류).

## 데이터

작품(`artworks`) 문서에 선택 필드를 추가한다. 기존 작품은 필드가 없으면 평면 작품이다.

| 필드 | 값 |
|---|---|
| `kind` | `flat`(기본) · `object` |
| `depthCm` | 10~500 (오브제만) |
| `model` | `{path, name}` — GLB 경로. 갤러리 `virtualGalleries/{g}/{a}/{uuid}.glb`, 제출함 `virtualSubmissions/{s}/{a}/{uuid}.glb`(수정본은 대상 갤러리 경로도 허용) |
| `spot` | 방 크기별 전시 자리 ID |
| `yaw` | 0~359 정수, 앞면 방향 보정 |
| `plinth` | `none` · `low`(10cm) · `high`(60cm) |
| `copies` | 1~5, 연작 수량 |

오브제도 대표 사진(`image`)은 필수다. 목록, 상세, 공유카드, 메인페이지에 쓴다. 벽 배치 필드(`wall`, `frame`)는 기존 검증을 위해 기본값을 유지하고 렌더에서는 쓰지 않는다.

## 전시 자리

| 방 | 모서리 | 중앙 |
|---|---|---|
| 소 10×8m | 앞 두 모서리 | 1곳 |
| 중 13×11m | 네 모서리 | 1곳 |
| 대 16×14m | 네 모서리 | 2곳 |

- **위치:** 모서리 자리는 두 벽에서 각 1.2m 안쪽에 있고, 방 중앙을 바라본다. 벽 작품 앞을 가리면 저장할 때 거절한다(벽 작품 너비 + 오브제 반경 + 30cm).
- **크기 제한:** 모서리 자리는 한 변 1.8m, 중앙 자리는 3m 안에 맞아야 한다(연작은 줄지어 놓은 전체 길이 기준).
- **중복 금지:** 한 자리에는 한 작품만 놓는다. 저장할 때 검사한다.
- **충돌:** 오브제마다 원형 충돌 영역(작품 크기의 절반 + 1m)을 둔다. 모서리 자리는 벽이 뒤를 막으므로 자연히 앞쪽에서만 볼 수 있다.

## 렌더링

- `three-r128-GLTFLoader.js`(three@0.128.0 공식 파일)로 GLB를 불러온다.
- **크기와 방향:** 모델 경계 상자의 높이를 입력한 `heightCm`에 맞춰 비율 그대로 확대·축소하고, 바닥(또는 좌대 윗면)에 세운다. 앞면은 자리 방향에 `yaw`를 더해 돌린다.
- **좌대와 조명:** 좌대는 흰 상자로 그리고, 자리마다 위에서 비추는 조명과 바닥 경계선(모서리 자리)을 둔다.
- **연작:** `copies`만큼 복제해 자리의 가로 방향으로 0.3m 간격으로 줄지어 놓는다.
- **클릭:** 클릭하면 작품 상세가 열린다. 가이드 투어와 `#art-` 주소는 자리 앞 3m에서 바라본다.
- **실패 처리:** 모델을 불러오지 못하면 대표 사진을 좌대 위에 세워 대신 보여준다.

## 업로드와 보안

- **파일 조건:** 압축하지 않은 GLB, 30MB 이하.
- **브라우저 검사:** 업로드 전에 GLB 헤더(`glTF`, 버전 2)와 `extensionsRequired`를 읽는다. Draco·meshopt 압축 파일이면 "압축하지 않은 GLB로 내보내 주세요"로 거절한다.
- **Worker 검사:** `.glb` 경로를 허용하고, `model/gltf-binary`·30MB·`glTF` 서명을 검사한다. 공개 GET은 작품 문서의 `model.path`가 일치할 때 허용한다. 제출함 접근, `/copy`, 정리(`purge`) 규칙은 이미지와 같다.
- **Firestore 규칙:** 새 필드의 형식과 범위, 모델 경로를 검사한다.

## 화면

관리자 작품 편집과 작가 업로드 화면 모두 같다.

- **종류 선택:** "평면 / 오브제 · 설치"를 고르는 칸을 둔다.
- **오브제를 골랐을 때:**
  - 가로·깊이·높이, 전시 자리(방 크기에 맞는 목록), 좌대, 연작 수량, 앞면 방향(0~359° 슬라이더), GLB 업로드, 대표 사진을 받는다.
  - 3D 파일을 만드는 방법(스캔 앱, 무료 웹 생성)을 짧게 안내한다.
- **평면을 골랐을 때:** 지금 그대로다.

## 범위 밖

AI 자동 생성, Draco·meshopt 압축 해제, 자유 위치 드래그 배치, 오브제용 벽 캡션.

## 검증

- **단위 테스트:** 자리 계산, 충돌, 검증 규칙, GLB 헤더 검사.
- **Worker 테스트:** GLB 업로드·서명·크기 검사, 공개 GET.
- **규칙 에뮬레이터 테스트:** 새 필드의 형식·범위·모델 경로.
- **브라우저(데모):** 작은 GLB를 만들어 세 방 크기에서 배치, 충돌, 클릭, 투어를 확인한다.
- **배포 순서:** 규칙 → Worker → 머지.
