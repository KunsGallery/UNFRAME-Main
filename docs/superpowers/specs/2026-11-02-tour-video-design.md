# 버추얼 갤러리 투어 영상 모드 설계

작성일: 2026-11-02 · 상태: 방향 승인, 문서 검토 대기

## 목표

기존 30초 세로 릴스 옆에, 2022년 Unity 버추얼 갤러리 소개 영상(Kün's Gallery, 55초)처럼 **전시장을 안내받으며 걷는 느낌의 가로 홍보 영상**을 만든다. 유튜브·홈페이지·전시 소개용이다.

**성공 기준**
- 관리자가 릴스 만들기 창에서 "투어 영상"을 골라 약 50초 16:9 MP4를 만든다.
- 로고 오프닝, 움직이는 큰 글자, 공간 라벨, 작품 클로즈업, QR 코드 엔딩이 들어간다.
- 음악·박자 맞춤, MP4 저장, 다크 뮤지엄 조명은 기존 기능을 그대로 쓴다.
- 나중에 여러 공간(홀·복도)이 있는 큰 전시장이 생기면 장면 목록에 공간을 추가하는 것만으로 대응한다.

## 형식

| 항목 | 릴스(기존) | 투어 영상(신규) |
|---|---|---|
| 비율 | 9:16 | **16:9**(기본) · 9:16 선택 |
| 해상도 | 720×1280 / 1080×1920 | **1280×720 / 1920×1080** (세로는 릴스와 같음) |
| 길이 | 30초 | **약 50초**(작품 수에 따라 40~60초) |
| 작품 | 최대 3점 | **최대 6점** |

## 장면 구성

장면은 `{type, duration, …}` 목록이고, 타임라인은 이 목록에서 계산한다. 공간이 늘면 `space` 장면만 추가하면 된다.

| 순서 | 장면 | 길이 | 내용 |
|---|---|---|---|
| 1 | **로고 오프닝** | 3초 | 검은 화면에 UNFRAME 워드마크와 "ART WITHOUT A FRAME"이 나타났다 사라짐 |
| 2 | **키네틱 타이틀** | 4초 | "Introducing" → "Virtual Gallery" → 전시 제목 → 작가가 차례로 등장(박자 맞춤 시 비트마다) |
| 3 | **공간 진입** | 5초 | 입구에서 방 안쪽으로 천천히 걸어 들어감. 왼쪽 아래 공간 라벨("전시장") |
| 4 | **작가 노트** | 4초 | 작가 노트(없으면 전시 소개)의 문장이 큰 글씨로 화면을 가로질러 흐름. 배경은 흐린 공간 장면 |
| 5 | **작품 투어** | 작품당 4초 | 작품으로 다가가 화면 가득 클로즈업 → 라벨(작품명 · 작가 · 연도). 벽이 바뀌면 라벨 "정면 벽 / 왼쪽 벽 / 오른쪽 벽", 오브제는 천천히 돌며 "바닥 오브제" |
| 6 | **공간 전체** | 4초 | 방 중앙에서 천천히 돌아보는 넓은 장면 |
| 7 | **로고 엔딩** | 3초 | 입구 쪽으로 물러나며 어두워지고 로고 |
| 8 | **QR 엔딩** | 5초 | QR 코드(버추얼 갤러리 주소) + "버추얼 갤러리 바로가기" + `@unframe.kr` + 전시 제목·기간 |

- 작품이 6점이면 3+4+5+4+24+4+3+5 = **52초**, 3점이면 40초.
- 박자 맞춤을 켜면 각 장면의 경계를 가장 가까운 마디로 맞추고, 전체 길이는 마디 단위로 반올림한다.

## 화면 표현

- **라벨:** 왼쪽 아래, 반투명 흰 바탕 칩에 검은 글씨(참고 영상과 같은 위치). 16:9에서는 아래 12% 위, 9:16에서는 릴스 안전 영역 안.
- **글꼴:** 공유 카드와 같은 Noto Serif KR(제목) + Noto Sans KR(본문).
- **키네틱 글자:** 크게(화면 높이의 12~18%), 흰색, 장면 안에서 미끄러지듯 이동하고 페이드.
- **QR:** 흰 바탕 정사각형, 화면 높이의 40%. `qrcode-generator@1.4.4`(MIT)를 jsDelivr에서 버전 고정으로 불러오며, 투어 영상을 만들 때만 받는다.
- **로고:** 글자 워드마크(이미지 파일 없음). 사이트 헤더와 같은 굵은 산세리프 + 작은 태그라인.

## 화면(관리자)

- 릴스 만들기 창 맨 위에 **"영상 종류: 릴스(30초 · 세로) / 투어 영상(약 50초 · 가로)"** 선택을 둔다.
- 투어 영상을 고르면 작품 선택이 최대 6점, 영상 크기 목록이 가로 해상도로 바뀌고, "세로로 만들기" 체크가 생긴다.
- 작가 노트는 갤러리 설정의 작가 노트를 기본값으로 채우고 수정할 수 있다(이 영상에만 쓰임, 저장하지 않음).
- 파일 이름: `UNFRAME_<전시제목>_tour.mp4`.

## 구조

- `js/virtual-reel.js`의 카메라·오버레이·녹화 루프를 재사용한다.
- 새 모듈 `js/tour-video.js`: 장면 목록 만들기(`tourScenes(works, options)`), 시간 → 장면·진행률(`tourShot`), 장면별 카메라(`tourView`), 장면별 그리기(로고·키네틱·라벨·QR).
- 녹화 루프는 "지금 시각의 카메라와 오버레이를 그린다"만 알게 하고, 릴스/투어는 각자의 타임라인 함수를 넘긴다.
- 방 관련 정보는 `room.reelInfo()`에서 받는다. 큰 전시장이 생기면 `reelInfo`가 공간 목록을 돌려주고 `tourScenes`가 공간마다 `space` 장면을 넣는다.

## 범위 밖

여러 공간 전시장 자체, 장면 순서 직접 편집, 영상 안 자막 언어 전환, 서버 저장.

## 검증

- **단위 테스트:** 장면 목록 길이(작품 수별), 박자 맞춤 시 장면 경계가 마디 위, 시간 → 장면 매핑, 투어 카메라가 방 안에 있고 클로즈업 대상 작품을 향함, 라벨·QR 위치가 화면 안(16:9, 9:16).
- **브라우저(데모):** 투어 영상 미리보기와 녹화(1280×720 MP4, 약 50초), 녹화된 파일에서 장면별 프레임 확인, 음악 포함 녹화, 세로 버전.
