# UNFRAME pen — two-part long-form design proposal

Preview design only; not applied to the existing pen product yet. Based on the actual staff-owned pen and packaging photographs already stored in private R2. Existing live pen detail assets remain unchanged.

Sheet 1: brand story, five body colors, macro details, lifestyle transition.
Sheet 2: actual package design, lifestyle uses, confirmed/unknown specifications, FAQ and Imweb checkout presentation.

New staging is illustrative. Preserve product silhouette, white grooved lower body, pastel upper body, tinted transparent click button and blue UNFRAME logo. Do not invent ink, tip width, dimensions, material, price or set composition. Final sales imagery should be checked against the actual photographs.
